# موتور مستقل بک‌تست تاریخی BTC – Kraken Futures

## فایل‌ها
- `backtest_independent.py` موتور مستقل بک‌تست
- `requirements.txt` وابستگی‌های Python

## اجرا
```bash
python -m pip install -r requirements.txt
python backtest_independent.py
```

## آزمون آفلاین
```bash
python backtest_independent.py --self-test
```

## مشخصات
- فقط قرارداد دائمی BTC با نماد `PF_XBTUSD` در Kraken Futures.
- ۳۰ روز دورهٔ آزمون به‌علاوهٔ ۱۰ روز warm-up.
- پیمایش کندل‌های بسته‌شدهٔ ۵ دقیقه از قدیمی به جدید.
- کشف چهار الگوی سه‌کندلی SQZMOM توافق‌شده و تأیید با آخرین کندل بسته‌شدهٔ Pure Momentum در ۱۵ دقیقه.
- محاسبهٔ Pure Momentum بر پایهٔ EMA روی OHLC، انحراف دوبرابری، WMA(45) و ATR/RMA(45)، با آستانه‌های ±۰٫۰۵ و حفظ روند قبلی.
- ورود در Open کندل ۵ دقیقهٔ بعدی؛ بدون نگاه به آینده.
- سرمایهٔ اولیه ۱۰۰ دلار، اهرم ۵۰، مارجین ایزوله و تخصیص ۱۰٪ موجودی آزاد برای هر ورود.
- هر سیگنال تأییدشده یک پوزیشن مستقل می‌سازد؛ BUY و SELL و معاملات هم‌جهت می‌توانند هم‌زمان باز باشند. سیگنال جدید معاملهٔ قبلی را نمی‌بندد.
- حد ضرر بر اساس حداقل/حداکثر ۱۰ کندل بسته‌شدهٔ قبلی ۱۵ دقیقه با بافر ۰٫۱٪؛ حد سود ۴R.
- Funding تاریخی Kraken دریافت می‌شود و به پوزیشن‌هایی اعمال می‌شود که در لحظهٔ تسویه باز بوده‌اند. نرخ مثبت برای BUY هزینه و برای SELL اعتبار است.
- کندل‌های تاریخی Mark Price در ۵ دقیقه برای تشخیص لیکوییدیشن و ارزش‌گذاری پایان داده استفاده می‌شوند؛ OHLC معاملات برای حد ضرر و حد سود استفاده می‌شود.
- اندازهٔ قرارداد از `contractSize` متادیتای Kraken خوانده می‌شود.
- گزارش Excel شامل Summary، Trade Ledger، Signal Log، Data Quality، Data Gaps و Assumptions است. هر الگوی SQZMOM که رد شود نیز در Signal Log با علت رد ثبت می‌شود.

## محدودیت‌های مهم
- این موتور مستقل است و هیچ کد، state، سیگنال یا زمان‌بندی Scanner 7 را import یا اجرا نمی‌کند.
- کارمزد و اسلیپیج فرضی‌اند (هر طرف ۰٫۰۵٪ و ۰٫۰۲٪).
- فرمول قیمت لیکوییدیشن و مارجین نگهداری، مدل تخمینی ایزوله است و بازسازی دقیق موتور ریسک/لیکوییدیشن Kraken نیست؛ اولویت در ابهام درون کندل با لیکوییدیشن Mark Price است.
- Funding بر اساس `relativeFundingRate` تاریخی و ارزش اسمی قرارداد اعمال می‌شود؛ قیمت Mark کندل قبلی برای settlement بررسی و الزامی است.
- اگر API خطا بدهد، کندل test window یا mark-price ناقص باشد، Funding ناقص باشد یا دادهٔ تسویهٔ موردنیاز وجود نداشته باشد، برنامه نتیجهٔ عملکرد تولید نمی‌کند.
- موفقیت self-test فقط منطق و آزمون‌های مصنوعی را بررسی می‌کند؛ اجرای واقعی ۳۰ روزه به دسترسی Kraken API و دادهٔ کامل نیاز دارد.
