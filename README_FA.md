# موتور مستقل بک‌تست BTC بر اساس کندل‌ها

## اجرا

```bash
pip install -r requirements_independent.txt
python backtest_independent.py --self-test
python backtest_independent.py
```

گزارش در فایل `independent_backtest_report.xlsx` ساخته می‌شود.

## منطق
- بازار Kraken Futures، قرارداد BTC perpetual با نماد `PF_XBTUSD`
- ۳۰ روز تست + ۱۰ روز دادهٔ گرم‌سازی
- محاسبهٔ مستقل رنگ‌های SQZMOM روی کندل‌های ۵ دقیقه‌ای و پیمایش از قدیمی به جدید
- بررسی الگوی سه کندل بسته‌شدهٔ اخیر
- تأیید با آخرین کندل بسته‌شدهٔ ۱۵ دقیقه‌ای Pure Momentum که تا زمان بسته‌شدن سیگنال ۵ دقیقه‌ای در دسترس بوده است
- ورود در بازشدن کندل ۵ دقیقه‌ای بعدی
- هر سیگنال تأییدشده یک معاملهٔ مستقل ایجاد می‌کند؛ معاملات BUY و SELL و معاملات هم‌جهت می‌توانند هم‌زمان باز باشند
- هر معامله مارجین ایزولهٔ خودش را دارد؛ ورود جدید ۱۰٪ موجودی آزاد همان لحظه را رزرو می‌کند
- اهرم فرضی ۵۰، حد ضرر پشت اکسترمم ۱۰ کندل بسته‌شدهٔ قبلی ۱۵ دقیقه‌ای با بافر ۰٫۱٪، حد سود ۴ برابر ریسک

## نکتهٔ مهم دربارهٔ دقت شبیه‌سازی
این نسخه مستقل است و هیچ کد یا خروجی‌ای از Scanner 7 اجرا نمی‌کند. نرخ کارمزد، اسلیپیج، مارجین نگهداری، لیکوییدیشن و اندازهٔ قرارداد فرض‌های شبیه‌سازی هستند. در این نسخه، دادهٔ تاریخی funding و mark-price هنوز وارد نشده‌اند؛ بنابراین گزارش نباید به‌عنوان بازسازی دقیق موتور لیکوییدیشن و هزینه‌های واقعی Kraken تلقی شود. همچنین فرمول Pure Momentum در این نسخه همان محاسبهٔ مستقل موجود در موتور تاریخی است؛ برای انطباق یک‌به‌یک با اندیکاتور TradingView باید سورس اصلی همان اندیکاتور در اختیار باشد.
